# Gamepath

Gamepath helps players turn a random pick into a focused game challenge. The first deliverable is a lightweight phase-based project tracker built with plain HTML, CSS, and JavaScript.

## Run locally

Open `index.html` in a modern browser. No build step or dependencies are required.

## Project roadmap

1. **Project map & guardrails** — agree on the MVP, rules, and game data.
2. **Core experience** — shape the game-to-role/category-to-character flow and challenge settings.
3. **Build the MVP** — implement a responsive UI and data-driven randomizer.
4. **Game content & progression** — add paths for Marvel Rivals, VALORANT, and FC 27.
5. **Test, polish & launch** — validate, refine, deploy, and learn from player feedback.

The interactive checklist saves progress in this browser using local storage. The first tracker-building step is pre-completed; future steps can be checked off as they are delivered. Reset returns the checklist to that initial state.
